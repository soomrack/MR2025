## Обзор проекта

Система предназначена для мониторинга состояния Linux-машины в реальном времени. Сервер периодически собирает метрики хоста (температура CPU, использование RAM, аптайм), параллельно читает данные с подключённого Arduino по UART и рассылает всё это подключённым клиентам по TCP. Клиент позволяет в интерактивном режиме запрашивать накопленные логи.

**Стек:**

- Язык: C++17 (сервер и клиент), Arduino C (скетч)
- Транспорт: TCP/IP, POSIX Sockets
- Платформа: Linux (Ubuntu/Debian), Arduino (AVR/ARM)

## Компоненты

### Сервер (`Server.cpp`)

Центральный узел системы. Запускается как единственный долгоживущий процесс.

#### Потоки выполнения

| Поток | Функция | Описание |
|---|---|---|
| `monitorLoop` | Мониторинг хоста | Каждые `MONITOR_INTERVAL_SEC` секунд собирает метрики и рассылает их всем клиентам через `broadcast()` |
| `arduinoLoop` | Чтение Arduino | Открывает UART-порт, читает строки побайтово, пишет в `arduino.log` с временной меткой |
| `acceptLoop` | Приём подключений | Неблокирующий цикл принятия входящих TCP-соединений |
| `handleClient` | Обслуживание клиента | По одному потоку на каждого подключённого клиента; читает команды, отвечает через `processLogCommand()` |

#### Сбор метрик

Данные берутся непосредственно из виртуальной файловой системы Linux:

- **Температура CPU** — `/sys/class/thermal/thermal_zone0/temp` (сырое значение делится на 1000)
- **Использование RAM** — `/proc/meminfo`, поля `MemTotal` и `MemAvailable`
- **Аптайм** — `/proc/uptime`

#### Предупреждения

Сервер автоматически генерирует предупреждения и рассылает их всем клиентам:

- `[WARNING] CPU TEMP HIGH` — если температура CPU превысила `CPU_TEMP_LIMIT` (по умолчанию 70 °C)
- `[WARNING] RAM HIGH` — если использование RAM превысило `RAM_LIMIT_PERCENT` (по умолчанию 80 %)

#### Управление памятью

Последние `LOG_BUFFER_MAX` (1000) строк хранятся в `logBuffer` — кольцевом буфере в оперативной памяти. Команды, требующие полную историю (`LOG ALL`, `LOG WARNINGS`), читают файл `server.log` с диска. Команды с временным окном (`LOG LAST`) работают через быстрый буфер в памяти.

### Клиент (`Client_Linux.cpp`)

Консольный клиент для Linux. Подключается к серверу по TCP и работает в двух режимах одновременно:

- **Фоновый приём** (главный поток): непрерывно получает сообщения от сервера (метрики и ответы на запросы) и выводит их в `stdout`.
- **Ввод команд** (отдельный поток): читает команды из `stdin` и отправляет их серверу.

#### Запуск

```bash
./client [host]
```

Если `host` не указан, подключается к `127.0.0.1`. Порт всегда `54000`.

#### Пример сессии


### Arduino (`sketch_jun7a.ino`)

Простейший скетч — датчик аналогового сигнала.

```cpp
void setup() {
    Serial.begin(9600);    // инициализация UART на 9600 бод
}

void loop() {
    Serial.println(analogRead(A0));  // отправка значения с пина A0
    delay(100);                       // интервал 100 мс (10 измерений/сек)
}
```

**Что делает:**

- Читает аналоговое значение с пина `A0` (0–1023 для 10-битного АЦП).
- Передаёт значение в UART в текстовом виде с символом перевода строки.
- Повторяет каждые 100 миллисекунд.

**Назначение пина A0:** Зависит от подключённого датчика (потенциометр, датчик освещённости, температуры и т.д.). Скетч универсален — интерпретация значений остаётся на стороне сервера или аналитики.

## Сетевой протокол

Все сообщения (в обоих направлениях) передаются по одному формату:

```
┌─────────────────────┬─────────────────────────┐
│   uint32_t (4 байт) │   N байт (UTF-8 текст)  │
│   длина тела (N)    │   тело сообщения        │
└─────────────────────┴─────────────────────────┘
```

- Поле длины передаётся в сетевом порядке байт (big-endian через `htons`/`ntohs` не используется — передаётся как есть через `memcpy`; обе стороны должны быть одной архитектуры).
- Тело сообщения — произвольная UTF-8 строка.
- Максимальный размер принимаемой команды на сервере: **65 536 байт**.

Функции `sendAll` / `recvAll` гарантируют полную передачу через цикл с повторными вызовами `send`/`recv`.

## Команды

Команды нечувствительны к регистру — клиент приводит их к верхнему регистру перед отправкой.

| Команда | Описание | Источник данных |
|---|---|---|
| `LOG ALL` | Полный лог сервера | `server.log` (файл) |
| `LOG WARNINGS` | Только строки с `[WARNING]` | `server.log` (файл) |
| `LOG LAST <мин>` | Записи за последние N минут | `logBuffer` (память) |
| `ARDUINO ALL` | Полный лог Arduino | `arduino.log` (файл) |
| `ARDUINO LAST <мин>` | Записи Arduino за последние N минут | `arduino.log` (файл) |
| `HELP` | Справка (только на клиенте, не отправляется) | — |
| `QUIT` / `EXIT` | Завершить клиент (не отправляется) | — |

## Конфигурация

Все параметры задаются константами в начале соответствующих файлов.

### Server.cpp

| Константа | Значение по умолчанию | Описание |
|---|---|---|
| `PORT` | `54000` | TCP-порт сервера |
| `MONITOR_INTERVAL_SEC` | `10` | Интервал сбора метрик (секунды) |
| `CPU_TEMP_LIMIT` | `70.0` | Порог температуры CPU для предупреждения (°C) |
| `RAM_LIMIT_PERCENT` | `80` | Порог использования RAM для предупреждения (%) |
| `LOG_BUFFER_MAX` | `1000` | Максимум строк в кольцевом буфере в памяти |
| `ARDUINO_PORT` | `"/dev/ttyACM0"` | Путь к UART-порту Arduino |
| `ARDUINO_BAUD` | `B9600` | Скорость UART |
| `ARDUINO_LOG` | `"arduino.log"` | Файл лога данных с Arduino |

### Client_Linux.cpp

| Константа | Значение по умолчанию | Описание |
|---|---|---|

## Логирование

Сервер ведёт два лог-файла в текущей рабочей директории:

### `server.log`

Содержит все события сервера: запуск/остановку, подключения клиентов, метрики мониторинга, предупреждения.

Формат строки:
```
[YYYY-MM-DD HH:MM:SS] <текст события>
```

Пример:
```
[2025-06-07 14:00:00] === Server started ===
[2025-06-07 14:00:00] Listening on port 54000
[2025-06-07 14:00:10] CPU: 44.1 C | RAM: 58% (3810 MB / 8192 MB) | Uptime: 0h 0m 10s
[2025-06-07 14:00:10] Connected: 192.168.1.5:51234
[2025-06-07 14:02:15] [WARNING] CPU TEMP HIGH (71.2 C)
```

### `arduino.log`

Содержит сырые значения, полученные с Arduino, с временными метками.

Формат строки:
```
[YYYY-MM-DD HH:MM:SS] <значение>
```

Пример:
```
[2025-06-07 14:00:11] 512
[2025-06-07 14:00:11] 498
[2025-06-07 14:00:11] 503
```

## Сборка и запуск

### Зависимости

- Компилятор с поддержкой C++17 (`g++ 7+` или `clang++ 5+`)
- Стандартная библиотека POSIX (входит в любой дистрибутив Linux)
- Arduino IDE или `arduino-cli` для загрузки скетча


### Запуск

```bash
# 1. Запустить сервер (в фоне или отдельном терминале)
./server

# 2. Подключиться клиентом (локально)
./client

# 3. Подключиться клиентом к удалённому серверу
./client 192.168.1.10
```
