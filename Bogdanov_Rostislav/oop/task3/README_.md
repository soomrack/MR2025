# 1. Описание

Chat Sensor Server — это многопользовательский TCP-чат на C++, который:

- поддерживает несколько клиентов
- логирует события в единый файл `server.log`
- мониторит систему (CPU, RAM, uptime)
- получает данные с Arduino через последовательный порт
- накапливает предупреждения Arduino для просмотра по команде `/errs`
- позволяет включать/отключать вывод логов Arduino в реальном времени через `/swlog`

# 5. Работа с логами

Сервер ведёт **один файл** `server.log`, в который записываются:
- все события чата (подключения, отключения, сообщения)
- результаты мониторинга системы (каждые 10 секунд)
- все строки, полученные от Arduino (как LOG, так и WARNING)

Пример содержимого `server.log`:
```
[2026-05-26 14:22:10] === Server started ===
[2026-05-26 14:22:10] MONITOR | CPU: 45 C | RAM: 30% | Uptime: 2h 15m
[2026-05-26 14:22:15] [ARDUINO] LOG: analog=512, voltage=2.50 V
[2026-05-26 14:22:17] [ARDUINO] WARNING: High value! analog=850, voltage=4.15 V
[2026-05-26 14:22:20] Client 192.168.1.12 joined as 'Alex'
```

**Внутренние буферы** (для ответов клиентам):
- `logBuffer` – все строки `server.log` (кроме предупреждений отдельно)
- `warningBuffer` – только строки, содержащие `[WARNING]`

По команде клиента `/logs all` / `/logs warnings` / `/logs last N` сервер возвращает соответствующие записи.

# 6. Мониторинг системы

Каждые 10 секунд сервер проверяет:
- CPU temperature
- RAM usage
- System uptime

Пороговые значения (задаются в коде):
```cpp
CPU_TEMP_LIMIT = 70.0°C
RAM_LIMIT_PERCENT = 20%
```

Если значение превышено:
- в консоль сервера выводится красное предупреждение
- запись добавляется в `server.log`
- сообщение рассылается **всем клиентам** (как системное уведомление)

# 7. Датчики Arduino

Arduino подключается через USB и передаёт строки в формате:

- **Обычные логи** – строка начинается с `LOG:`
- **Предупреждения** – строка начинается с `WARNING:`

Пример реальных данных (скетч `arduino_sensor.ino`):
```
LOG: analog=234, voltage=1.14 V
LOG: analog=512, voltage=2.50 V
WARNING: High value! analog=820, voltage=4.01 V
```

## Порог предупреждения

В прошивке Arduino задаётся константа `WARNING_THRESHOLD` (например, 800). Если аналоговое значение превышает этот порог, вместо обычного лога отправляется предупреждение.

## Обработка на сервере

- Строки **всегда** записываются в `server.log` (через `logEvent`).
- Если строка начинается с `WARNING:`, она **сохраняется** в отдельный буфер `arduinoWarnings` для последующего показа по команде `/errs`.
- Вывод в **консоль сервера**:
  - для обычных логов (`LOG:`) – только если включён режим реального времени (`/swlog`)
  - для предупреждений (`WARNING:`) – только если включён `/swlog` (однако буфер `/errs` накапливается всегда, независимо от режима)

Команда `/errs` выводит все накопленные предупреждения (с момента последнего вызова) и **очищает** буфер.

Команда `/swlog` переключает отображение **всех** логов Arduino (и LOG, и WARNING) в консоль сервера. По умолчанию – выключено.

# 8. Команды сервера

Команды вводятся в консоль сервера (через stdin).

| Команда       | Действие |
|---------------|----------|
| `/shutdown`   | Остановка сервера |
| `/status`     | Показать количество подключённых клиентов |
| `/time`       | Текущее системное время |
| `/uptime`     | Время работы сервера |
| `/ram`        | Использование RAM в % и MB |
| `/cpu`        | Температура CPU |
| `/errs`       | Показать **все накопленные предупреждения Arduino** (с момента последнего вызова) и очистить буфер |
| `/swlog`      | Включить/выключить вывод логов Arduino в реальном времени в консоль сервера |
| `/help`       | Список команд |

## Примеры
```
/status
Clients: 3
```
```
/cpu
CPU temp: 42 C
```
```
/swlog
Realtime Arduino logging: ENABLED
```
```
/errs
=== Arduino warnings (2 entries) ===
  WARNING: High value! analog=850, voltage=4.15 V
  WARNING: High value! analog=920, voltage=4.50 V
=========================================
```

# 9. Команды клиента

Клиентские команды (вводятся после подключения к серверу):

| Команда                          | Действие |
|----------------------------------|----------|
| `/connect <ip> <port>`           | Подключиться к серверу |
| `/quit`                          | Отключиться (без выхода из клиента) |
| `/exit`                          | Отключиться и закрыть клиент |
| `/help`                          | Справка по командам |
| `/spam <count> <message>`        | Отправить сообщение много раз |
| `/logs all`                      | Получить весь лог `server.log` |
| `/logs warnings`                 | Получить только строки с `[WARNING]` |
| `/logs last <minutes>`           | Получить логи за последние N минут |

**Примечание:** клиент не может запрашивать отдельные логи (server/board/sensor) – все логи хранятся в едином `server.log`. Формат ответа – сырой текст лога.

# 10. Запуск

## Сервер (Raspberry Pi / Linux)

Компиляция:
```bash
g++ Server_Linux.cpp -std=c++11 -pthread -o server
```
Запуск:
```bash
./server
```

Перед запуском убедитесь, что:
- Arduino подключена и видна как `/dev/ttyACM0` (или `/dev/ttyUSB0`). При необходимости измените путь в коде.
- Пользователь имеет права на чтение/запись последовательного порта:
  ```bash
  sudo usermod -a -G dialout $USER
  # затем перезайдите в систему
  ```

## Клиент (Windows)

Компиляция (MinGW):
```bash
g++ client.cpp -lws2_32 -o client.exe -std=c++11
```
Запуск:
```bash
client.exe
```

## Arduino

Загрузите скетч `arduino_sensor.ino` (пример ниже):
```cpp
const int WARNING_THRESHOLD = 800;
void setup() {
    Serial.begin(9600);
    pinMode(A0, INPUT);
}
void loop() {
    int value = analogRead(A0);
    float volt = value * (5.0 / 1023.0);
    if (value > WARNING_THRESHOLD) {
        Serial.print("WARNING: High value! analog=");
        Serial.print(value);
        Serial.print(", voltage=");
        Serial.print(volt);
        Serial.println(" V");
    } else {
        Serial.print("LOG: analog=");
        Serial.print(value);
        Serial.print(", voltage=");
        Serial.print(volt);
        Serial.println(" V");
    }
    delay(2000);
}
```

# Потоки сервера

Сервер использует несколько потоков:

- **Main thread** – цикл принятия новых клиентов (`runAcceptLoop`)
- **Client thread** – для каждого подключённого клиента (`handleClient`)
- **Command thread** – чтение команд из консоли (`commandHandler`)
- **Monitoring thread** – мониторинг системы (`monitoringLoop`)
- **Arduino thread** – чтение данных с последовательного порта (`arduinoReadLoop`)

---

# Ограничения

- Максимальный размер сообщения: 1 MB
- Количество клиентов ограничено ресурсами системы (обычно до нескольких сотен)
- Предупреждения Arduino хранятся в памяти до вызова `/errs` (для долгой работы без `/errs` потребление памяти растёт)
